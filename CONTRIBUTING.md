To contribute:
1. Fork the `master` branch of this repository.
2. Make and test your changes.
3. Open a pull request with a description of what's been changed and how it was tested.

Note that this project adheres to the [SciActive Human Contribution Policy 2-UP](HUMAN-CONTRIBUTION-POLICY-2-UP.md).  No AI contributions of any kind are allowed directly to this repository.  This includes both code and text - your pull request should be written by you, not an LLM.  Anyone found to be using AI to contribute to this project will be permanently blocked from contributing.

This repository has an upstream reliance on []Jellyfin](https://github.com/orgs/jellyfin) [repositories](https://github.com/orgs/jellyfin/repositories) such as [jellyfin-plugin-template](https://github.com/jellyfin/jellyfin-plugin-template).  This repository also interacts with [Jellyfin-JavaScript-Injector](https://github.com/n00bcodr/Jellyfin-JavaScript-Injector) and [jellyfin-apiclient-javascript](https://github.com/jellyfin-archive/jellyfin-apiclient-javascript/).  Contributions to the aforementioned projects are not governed by this contribution policy.
